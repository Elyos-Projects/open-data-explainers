# Contributing to open-data-explainers

> **License:** CC-BY-4.0

Thank you for helping improve open-data-explainers. This guide covers how to report errors, suggest improvements, and contribute work.

## Found an error?

If you spot an incorrect figure, stale data, misleading claim, or broken link in an explainer:

1. **Open a [GitHub issue](https://github.com/Hee-Lee-Oss-Projects/open-data-explainers/issues)** with the `correction` label, or use our [correction template](.github/ISSUE_TEMPLATE/correction.md).
2. **Include:**
   - Which explainer (name and link)
   - What's wrong (the incorrect claim or figure)
   - Why it's wrong (cite a source)
   - When you noticed it (date, if relevant)

3. **Expect an acknowledgment within 5 business days.** See our [Corrections Process](./CORRECTIONS.md) for severity levels, timelines, and how fixes are logged.

## Contributing a new explainer or module

- Review the [PLAN.md](./PLAN.md) to see which regions/modules are planned.
- Check [TASKS.md](./TASKS.md) for available task slots.
- Use the [Hee-Lee Oss workflow](https://github.com/Hee-Lee-Oss-Projects/hee-lee-oss-downloads) to pull a task.
- Deliverables are reviewed by a domain expert before merge.

## Code of conduct

- Be respectful and constructive in all communication.
- Prioritize accuracy and honesty; flag limitations and caveats.
- Respect licenses and data provenance; always cite sources.

## Questions?

- See the [Corrections Process](./CORRECTIONS.md) FAQ for common questions.
- Open an issue or reach out to the maintainer listed in [README.md](./README.md).
